# MERN Deployment Checklist

- Set production environment variables and verify required configuration.
- Use HTTPS and restrictive CORS settings.
- Confirm authentication and authorization on protected endpoints.
- Apply database migrations or indexes deliberately.
- Configure health checks, structured logs, and error monitoring.
- Verify backups and test a restore procedure.
- Run tests and build checks before release.
- Ensure secrets and local environment files are not committed.

A successful build is useful; it is not proof that a production system is secure or recoverable.
